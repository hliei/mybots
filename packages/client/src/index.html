    Long-term memory

    Index and definition load on later Runs, up to 16,000 characters each. Topics stay in files until a Bot reads them. Deleting a file stops that loading. It does not erase conversation history or guarantee forgetting, and a later save can record a fact again. Mutable external facts still need a current check at their source. A save compares the version you read; an intervening edit is shown for rereading. Agent and owner writes can still race, with no automatic merge.

    Delegation
    
            
    Directed collaboration defaults to deny. Allow lets this Bot delegate selected text to the named Bot. This Bot cannot grant itself, and the reverse direction needs its own permission. Ask each time requires a local decision for the exact target and inputs before creating child work.
    
            
    
              
              
              
              
              
            
    
            
    
            
          
    
        
    
            
    Routines
    
            
    
              
              
              
            
    
            
    
            
            
    Cron uses this Bot timezone (default Asia/Shanghai). Changes apply immediately to future scheduling. Admitted work and one-shot instants stay fixed. Missed slots create no backlog; one unfinished occurrence blocks the next.
    
            
    Work runs while the Host is available, even after you disconnect. Each occurrence gets its own Task and independent Run context. Include any selected prior inputs in the instructions.
    
            
    Pause blocks automatic starts and lets current work finish. Resume skips cron slots missed while paused; an overdue one-shot runs once. Run now works while paused and does not turn recurrence back on. Deleting a Routine cancels unfinished occurrences and future starts, and keeps the definition and results. Stopping one occurrence does not pause or delete the Routine. An explicit retry keeps the Task and the earlier Run outcome.
    
            
    
              
              
              
              
              
    
              
              
              
              
              
    
              
    
                
                
                
    Five numeric fields: minute, hour, day of month, month, weekday. Cron follows local wall time. At a spring-forward gap a fixed hour shifts forward; during a repeated fall-back hour the parser can select the second instance. Results follow cron-parser 5.10.2.
